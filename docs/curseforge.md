# CurseForge project description

This is the text of the CurseForge project page, kept apart from the README (which is written for the
GitHub repository). Paste it into the description editor as Markdown. The screenshots under
`docs/screenshots` are uploaded on the project page by hand.

---

Select and copy any text in **WoW Forever**: chat, quests, dialogues, books, guild info, player and NPC
names, tooltips and web addresses. The game has no clipboard for addons, so Maldö's Scribe puts the text
into a window where it is already highlighted: press **Ctrl+C** and paste it anywhere.

## What it copies

- **Chat**: a small quill appears in the corner of a chat window while the mouse is over it. One click
  opens the whole history of that window as plain text, with item names instead of links and without
  icons or colour codes. Web addresses in chat are clickable and come up ready to copy.
- **Player names**: right-click a portrait, a target, a party or raid member, a guild member or a name in
  chat and pick **Copy name**. You get the full name, the first name and the surname. Alt+click on a name
  in chat does the same.
- **Quests, dialogues, books**: a **Copy quest** button beside the quest window and the quest log, the same
  beside NPC dialogues, books, plaques and letters. Text, name or the Wowhead link.
- **Guild**: a **Copy guild info** button beside the guild window: message of the day, guild information
  and the member list (tab-separated, ready for a spreadsheet).
- **Items and tooltips**: bind a key and press it while pointing at an item, spell or player: the name, the
  whole tooltip, the id or the Wowhead link.
- **Mail, macros, your group**: the open letter with sender, text, money and attachments, the draft you are
  writing or the whole inbox as a table; the text of a macro; the names of your party or raid.

## Commands and keys

`/scribe` copies what is open (tooltip, window or chat); `/scribe chat`, `/scribe quest`, `/scribe guild`,
`/scribe book`, `/scribe mail`, `/scribe macro`, `/scribe group`, `/scribe tooltip`, `/scribe options`,
`/scribe keys`. Three key bindings under
Key Bindings → Maldö's Scribe: copy what is open, copy the tooltip, copy the chat.

## Languages

English and German, following the game client; every other language uses English.

## Problems

The addon catches its errors and tells you in chat. `/scribe log` opens a report you can paste into an
issue on GitHub: https://github.com/nfMalde/MaldoesScribe/issues
